## 3. Замечания без правок (рекомендации)

- **УЧЕБНЫЙ_README.md (ias_uch_vnii/docs/guides):** В нескольких местах указаны представление `views/tasks/index-aggrid.php` и маршрут `tasks/index-aggrid`. Фактически используется представление `views/tasks/index.php` и маршрут `tasks/index`. Рекомендация: при следующем обновлении гайда заменить упоминания index-aggrid на index (либо оставить как историческое/альтернативное имя страницы с AG Grid).
- **SYSTEM_DESCRIPTION п. 1.2:** Упоминание «44 файла» — ориентировочное; при изменении состава документации число может устареть. Критичным не является.
- **Кодировка в config/db.php:** Указано `'charset' => 'utf8'`; для PostgreSQL кодировка задаётся на уровне сервера/БД. На соответствие документов это не влияет.
