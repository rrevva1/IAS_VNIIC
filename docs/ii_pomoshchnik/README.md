# Документация по ИИ-помощнику

Вся документация, относящаяся к встроенному ИИ-помощнику, LLM, RAG и интеграции ИИ в ИАС, собрана в этой папке.

| Документ | Описание |
|----------|----------|
| [ЗАПУСК_ПОМОЩНИКА.md](ЗАПУСК_ПОМОЩНИКА.md) | Запуск помощника, подключение LM Studio, векторный RAG (ChromaDB), переменные окружения. |
| [КАК_ПОЛЬЗОВАТЬСЯ_ПОМОЩНИКОМ.md](КАК_ПОЛЬЗОВАТЬСЯ_ПОМОЩНИКОМ.md) | Руководство пользователя: кнопка «Помощник», направления запросов, примеры, права доступа. |
| [ИНТЕНТЫ_ПОМОЩНИКА_И_LLM.md](ИНТЕНТЫ_ПОМОЩНИКА_И_LLM.md) | Набор интентов, распознавание в коде, параметры и ответы, варианты с LLM. |
| [ЛОКАЛЬНЫЕ_МОДЕЛИ_ПОМОЩНИК.md](ЛОКАЛЬНЫЕ_МОДЕЛИ_ПОМОЩНИК.md) | Локальные русскоязычные модели (RuBERT SberQuAD, ruDialoGPT и др.) для интеграции. |
| [ПРОЦЕСС_И_ВАРИАНТЫ_ИСПОЛЬЗОВАНИЯ_LLM_В_ПОМОЩНИКЕ.md](ПРОЦЕСС_И_ВАРИАНТЫ_ИСПОЛЬЗОВАНИЯ_LLM_В_ПОМОЩНИКЕ.md) | Процесс обработки запроса, места участия LLM, целевой процесс, варианты реализации. |
| [АНАЛИЗ_ИНТЕГРАЦИИ_ИИ.md](АНАЛИЗ_ИНТЕГРАЦИИ_ИИ.md) | Анализ направлений интеграции ИИ в ИАС (Help Desk, вложения, учёт ТС, справка). |

Связь с кодом: контроллер `app\controllers\AssistantController`, компоненты помощника в `app\components\assistant\`, RAG в `app\components\rag\`, конфигурация в `config/params.php` (параметры `llm_*`, `rag_*`).
