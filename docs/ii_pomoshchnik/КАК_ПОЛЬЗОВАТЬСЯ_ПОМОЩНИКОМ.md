# Как пользоваться ИИ-помощником

ИИ-помощник — это диалоговое окно в системе, через которое можно быстро получить данные по заявкам, технике, локациям и пользователям, не переходя в разделы меню. Помощник ориентируется по **направлениям**: заявки, техника по ответственному, техника по локациям, справочные данные (список кабинетов, список пользователей), справка.

---

## 1. Где находится помощник

- После входа в ИАС справа внизу экрана отображается **кнопка «Помощник»** (иконка робота и подпись).
- Кнопка доступна **всем авторизованным пользователям** (в том числе администратору).
- Если кнопки не видно — убедитесь, что вы вошли в систему; при необходимости обновите страницу (F5).

---

## 2. Как открыть панель чата

1. Нажмите кнопку **«Помощник»** справа внизу.
2. Справа откроется **панель** с заголовком «ИИ-помощник».
3. Внизу панели — **поле ввода** и кнопка **«Отправить»**.
4. Чтобы закрыть панель, нажмите **крестик** в заголовке панели.

---

## 3. Направления запросов

Помощник понимает запросы по следующим направлениям:

| Направление | Примеры запросов |
|-------------|-------------------|
| **Заявки (мои, где я автор)** | «Мои заявки», «заявки которые я создал», «где я автор» |
| **Заявки (где я исполнитель)** | «Заявки где я исполнитель», «что на мне висит», «заявки мне на исполнение» |
| **Заявки за период** | «Заявки за месяц», «заявки за неделю», «заявки за квартал», «заявки за год» |
| **Заявки по статусу** | «Открытые заявки», «закрытые заявки», «заявки в работе», «новые заявки», «выполненные» |
| **Все заявки** | «Заявки», «покажи заявки», «покажи все заявки» |
| **Статистика по заявкам** | «Статистика заявок», «статистика», «сколько заявок», «сводка заявок» |
| **Техника по ответственному** | «Техника Печерского», «покажи технику Иванова», «оборудование [ФИО]», «что закреплено за Ивановым», «инвентарь Петрова» |
| **Техника по кабинету/локации** | «Техника в кабинете 203», «оборудование в серверной», «какая техника в кабинете 205», «техника по кабинетам», «что в кабинете 203» |
| **Список локаций** | «Список кабинетов», «все локации», «какие кабинеты есть», «локации», «где что стоит» |
| **Список пользователей** | «Кто в системе», «список пользователей», «все ответственные», «пользователи» |
| **Справка по системе** | «Справка», «помощь», «как создать заявку», «инструкция», «что умеешь» |

Регистр не важен: можно писать и «Мои заявки», и «мои заявки».

---

## 4. Что вы получите в ответ

- **Краткое пояснение** — что именно было сделано (например: «Заявки за последний месяц»).
- **Таблица или список** — заявки, сводка по статистике, техника по ответственному/локации, список локаций или пользователей (в зависимости от запроса).
- **Ссылка** «Открыть в разделе Заявки», «Открыть раздел Статистика заявок», «Открыть в разделе Технические средства» или «Открыть раздел Пользователи» — по ней откроется тот же набор данных в основном интерфейсе ИАС, с уже подобранными фильтрами.
- Если запрос не удалось однозначно понять — помощник покажет **подсказки** с примерами формулировок по направлениям. При включённой локальной модели (LM Studio) может быть показан вежливый ответ с предложением примеров запросов.

Для запроса **«Справка»** отображается только текст подсказки по работе с системой, без таблицы.

---

## 5. Права доступа

- **Обычный пользователь** видит только **свои заявки** и заявки, где он назначен **исполнителем** (как и в разделе «Заявки»).
- **Оператор и администратор** видят **все заявки** в ответах помощника.
- Помощник **не выдаёт данные**, к которым у вас нет прав в ИАС (например, технику другого ответственного — только свою или при правах оператора/админа).

---

## 6. Если помощник не отвечает или пишет об ошибке

- Помощник работает в рамках основного приложения ИАС; отдельный сервис не требуется.
- Убедитесь, что вы **авторизованы** в системе и страница загружена полностью.
- При сообщении об ошибке обновите страницу (F5) и повторите запрос. Подробнее о настройке и опциональном подключении локальной модели — в [ЗАПУСК_ПОМОЩНИКА.md](ЗАПУСК_ПОМОЩНИКА.md).

---

## 7. Краткая последовательность действий

1. Войти в ИАС.
2. Нажать кнопку **«Помощник»** справа внизу.
3. Ввести запрос в поле внизу панели (например: **мои заявки**, **техника по кабинетам** или **справка**).
4. Нажать **«Отправить»** или клавишу **Enter**.
5. Прочитать ответ; при необходимости перейти по ссылке в соответствующий раздел (Заявки, Статистика заявок, Технические средства, Пользователи), чтобы работать с теми же данными в основном интерфейсе.
