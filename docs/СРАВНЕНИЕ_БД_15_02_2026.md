# Сравнение текущей БД проекта с дампом 15.02.2026

## Результат проверки

**Текущая БД** и **дамп ias_vniic_mac_15_02_26.sql** имеют **расхождения по схеме**.

---

## Расхождения

| Аспект | Текущая БД (проект) | Дамп 15.02.2026 |
|--------|---------------------|-----------------|
| **equipment.equipment_type** | нет (удалено) | есть (varchar) |
| **equipment.equipment_type_id** | есть (FK) | нет |
| **equipment_types** | есть | нет (удалена revert-миграцией) |
| **Миграции** | m260213_160000_equipment_types | m260215_100000 + m260215_120000 (revert) |

### Причина

В дампе применена миграция `m260215_120000_revert_to_dump_equipment_type`, которая вернула текст `equipment_type` и удалила справочник `equipment_types`. В текущей БД проекта справочник `equipment_types` и столбец `equipment_type_id` используются — приложение рассчитано на эту схему.

---

## Рекомендация

Прямое восстановление дампа **не рекомендуется**: оно приведёт к схеме с `equipment_type`, а приложение ожидает `equipment_type_id`.

Для переноса **данных** из дампа в проект создан скрипт `scripts/import_from_dump_15_02.php`, который:
- читает данные equipment из дампа;
- маппит `equipment_type` (текст) → `equipment_type_id` через справочник;
- вставляет/обновляет записи в текущей БД.

Запуск: `php scripts/import_from_dump_15_02.php` (из папки ias_uch_vnii).

**Результат последнего запуска:** обновлено 20 записей equipment (equipment_type_id проставлен по данным дампа).
