# Запуск ИИ-помощника (Assistant API)

## Быстрый старт

1. **Запустить Python-сервис** (один из способов):
   - Двойной клик по **`START_ASSISTANT_API.bat`** в корне проекта.
   - Или из папки `assistant_api`:
     ```bat
     pip install -r requirements.txt
     python -m uvicorn main:app --host 127.0.0.1 --port 8000
     ```

2. **Проверить:** в браузере открыть http://127.0.0.1:8000/health — должен быть ответ `{"status":"ok"}`.

3. **В ИАС:** войти под любым пользователем (в т.ч. **администратором**), справа внизу нажать кнопку **«Помощник»**, ввести запрос (например: «мои заявки», «справка», «статистика заявок»).

## Переменные БД

Если БД не localhost/postgres/ias_vniic, перед запуском задайте (в том же окне CMD):

```bat
set DB_HOST=localhost
set DB_NAME=ias_vniic
set DB_USER=postgres
set DB_PASSWORD=ваш_пароль
```

Затем запустите `START_ASSISTANT_API.bat` или uvicorn из папки `assistant_api`.

## Доступ под администратором

Кнопка «Помощник» и панель чата показываются **всем авторизованным пользователям**, включая администратора. Права на данные те же: админ видит все заявки, обычный пользователь — только свои и где он исполнитель.
