### Скрипты загрузки в БД

| Скрипт | Назначение |
|--------|------------|
| `scripts/load_ou_test_20rows.py` | Тестовая загрузка первых 20 строк листа АРМ из ОУ_тест.xlsx. |
| `scripts/load_ou_main.py` | Полная загрузка листов **АРМ** и **Принтеры**: `equipment`, `part_char_values`, пользователи, помещения, **связи комплекта** `equipment_links` (СБ → монитор/ИБП; число мониторов — `monitor_kit_entries`, регламент §5.1.5). |
| `scripts/link_ou_kits_only.py` | Только связи `equipment_links` по файлу OУ (если equipment уже загружен без связей). |

**Запуск полной загрузки:** `php yii migrate` и при чистовой загрузке `php yii purge/keep-admin --force=1` (из `ias_uch_vnii/`), затем из корня репозитория:  
`python3 scripts/load_ou_main.py`  
(файл в корне или `OU_MAIN_EXCEL`, зависимости: `pip install openpyxl psycopg2-binary`).  
Подробно — [РЕГЛАМЕНТ_ЗАГРУЗКИ_В_БД.md](РЕГЛАМЕНТ_ЗАГРУЗКИ_В_БД.md), чек-лист — [CHECKLIST_ЗАГРУЗКИ_В_БД.md](CHECKLIST_ЗАГРУЗКИ_В_БД.md).
