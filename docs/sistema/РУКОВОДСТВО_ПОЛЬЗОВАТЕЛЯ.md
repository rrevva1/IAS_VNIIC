# Руководство пользователя (Этап 6)

Краткое руководство по работе с системой учёта ТС для конечных пользователей.

## Вход в систему

Откройте в браузере адрес системы. При необходимости введите логин и пароль. После входа отображается главная страница (для администратора — список пользователей, для остальных — карточка своего профиля).

## Заявки (Help Desk)

- **Список заявок:** раздел «Заявки». Отображаются заявки в соответствии с правами (свои или все — для оператора и администратора). Можно открыть заявку, создать новую, изменить статус, назначить исполнителя, добавить комментарий. Удаление заявки доступно только администратору.
- **Создание заявки:** нажать «Создать заявку», заполнить описание, при необходимости выбрать связанные активы (технику) и приложить файлы. После сохранения заявка появится в списке.
- **Карточка заявки:** просмотр темы, описания, статуса, исполнителя, комментария, связанных активов и вложений. При наличии прав — редактирование, смена статуса, назначение исполнителя, удаление вложений. Скачивание вложений — по ссылкам в карточке.

## Учёт технических средств (активы)

Доступен администратору (список и все операции) и при необходимости оператору/ответственным (просмотр и редактирование своих активов по настройкам).

- **Список ТС:** раздел «Учёт ТС». Таблица с инв. номером, наименованием, статусом, ответственным, местоположением. Можно открыть карточку актива, создать новый актив, архивировать (админ).
- **Карточка актива:** просмотр и редактирование данных актива, конфигурации (характеристики), истории изменений и списка связанных заявок.

## ПО и лицензии

Раздел доступен только администратору. Ведётся справочник ПО и лицензий с указанием срока действия. В разделе доступен отчёт «Лицензии: истекающие и просроченные» для контроля сроков.

## Статистика и отчёты

- **Статистика заявок:** раздел «Заявки» → «Статистика». Диаграммы и таблицы по количеству заявок по пользователям и по завершённым заявкам по исполнителям. Доступен экспорт в HTML и сохранение в PDF через печать браузера.
- **Журнал аудита:** раздел доступен только администратору. Просмотр событий с фильтрами по дате, пользователю, типу операции.

## Импорт

Раздел «Импорт» доступен только администратору. Возможна загрузка данных из файла Excel (лист АРМ) и универсальный импорт из файлов CSV, JSON, XML, XLSX по согласованному формату. После загрузки отображается протокол (обработано записей, ошибки).

## Профиль и выход

Просмотр и при необходимости редактирование своего профиля — через соответствующий раздел. Выход из системы — кнопка «Выход».

При возникновении вопросов или проблем обращайтесь к администратору системы.
