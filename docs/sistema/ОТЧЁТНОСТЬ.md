# Отчётность и экспорт (ТЗ)

Документ фиксирует перечень отчётов системы и способы экспорта в PDF и HTML.

## Перечень отчётов

| Отчёт | Раздел / экшен | Описание |
|-------|----------------|----------|
| Статистика заявок по пользователям | Заявки → Статистика | Количество заявок по авторам (заявителям). Диаграмма и таблица. |
| Статистика завершённых заявок по исполнителям | Заявки → Статистика | Количество завершённых заявок по исполнителям. Диаграмма и таблица. |
| Лицензии: истекающие и просроченные | ПО и лицензии → Лицензии: истекающие и просроченные | Список просроченных лицензий и лицензий, истекающих в течение N дней. |
| Журнал аудита | Журнал аудита | Список событий аудита с фильтрами (дата, пользователь, тип операции). |

При необходимости вводятся дополнительные отчёты (по технике по подразделениям, по заявкам за период в разрезе статусов и т.п.) по согласованию с заказчиком.

## Экспорт в PDF и HTML

- **Статистика заявок:** на странице «Статистика» доступны кнопки экспорта в HTML и «Сохранить как PDF». PDF формируется средствами браузера (Печать → Сохранить как PDF) на основе сгенерированной HTML-страницы отчёта.
- **Лицензии (истекающие):** страница отчёта может быть распечатана или сохранена в PDF через стандартный диалог печати браузера (Ctrl+P → Сохранить как PDF).
- **Журнал аудита:** данные отображаются в AG Grid; при необходимости экспорт выполняется через встроенные средства грида (если подключены) или через печать страницы.

Формат экспорта: HTML — просмотр в браузере и сохранение страницы; PDF — через диалог печати браузера (рекомендуется для протоколов и отчётов). При необходимости серверной генерации PDF используется отдельная библиотека (например, mpdf, dompdf) и фиксируется в проектной документации.

## Доступ

Доступ к отчётам — в соответствии с матрицей прав (статистика заявок и журнал аудита — по ролям; отчёт по лицензиям — только администратор).
