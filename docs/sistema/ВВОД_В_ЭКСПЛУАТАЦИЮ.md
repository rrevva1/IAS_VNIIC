# Ввод в эксплуатацию (Этап 7)

Документ фиксирует параметры инфраструктуры, назначение ответственных и критерии приёмки при вводе системы в эксплуатацию.

## Параметры инфраструктуры

- **Сервер приложения:** веб-сервер (Apache 2.4+ / nginx) с поддержкой PHP 7.4+ (рекомендуется 8.x), развёртывание приложения в каталоге веб-сервера с правами доступа для процесса веб-сервера.
- **СУБД:** PostgreSQL 12+ на отдельном сервере или локально; БД ias_vniic, схема tech_accounting; кодировка UTF-8.
- **Сеть:** доступ пользователей к веб-интерфейсу по корпоративной сети; в эксплуатации рекомендуется использование HTTPS (TLS) для защиты передаваемых данных.
- **Резервное копирование:** настроенное по регламенту резервное копирование БД и при необходимости файлов приложения и загрузок.

Конкретные значения (имена серверов, версии ПО, размеры ресурсов) фиксируются в акте ввода в эксплуатацию или в приложении к нему.

## Назначение ответственных

- **Ответственный за администрирование системы:** назначение приказом или регламентом; права доступа администратора в системе; выполнение резервного копирования, обновлений и восстановления по регламенту.
- **Ответственный за содержание данных (при необходимости):** координация импорта, актуализация справочников, контроль истекающих лицензий.

## Начальное наполнение

- Выполнение миграции/импорта данных по [РЕГЛАМЕНТ_МИГРАЦИИ](../import_ou/РЕГЛАМЕНТ_МИГРАЦИИ.md).
- Создание учётных записей пользователей и назначение ролей.
- Проверка доступа и выполнения типовых сценариев (создание заявки, просмотр активов, отчёты).

## Критерии приёмки / акт ввода в эксплуатацию

- Система развёрнута на эксплуатационной инфраструктуре в соответствии с параметрами.
- Выполнены испытания по [ПРОГРАММА_ИСПЫТАНИЙ](ПРОГРАММА_ИСПЫТАНИЙ.md); критические замечания устранены.
- Назначены ответственные за администрирование; регламенты резервного копирования и восстановления согласованы.
- Начальное наполнение данных выполнено; контрольные сверки пройдены.
- Документация (руководство пользователя, руководство администратора) передана заказчику.

Подписание акта ввода в эксплуатацию осуществляется в соответствии с процедурами заказчика.
