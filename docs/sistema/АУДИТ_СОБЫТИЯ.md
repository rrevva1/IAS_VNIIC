# События журнала аудита

Документ фиксирует перечень типов операций (action_type) и типов объектов (object_type), записываемых в таблицу audit_events в соответствии с ТЗ п. 5.1.10.

## Атрибуты записи аудита

- Дата/время (event_time)
- Пользователь (actor_id)
- Тип операции (action_type)
- Тип объекта (object_type), идентификатор объекта (object_id)
- Результат (result_status: success, error, denied)
- Дополнительные данные (payload, JSONB)
- Сообщение об ошибке (error_message при result_status = error)
- Источник запроса (source_ip, user_agent) — по возможности

## Перечень операций (action_type)

| action_type | object_type | Описание |
|-------------|-------------|----------|
| auth.login | user | Успешный вход в систему |
| auth.logout | user | Выход из системы |
| user.password_reset | user | Сброс пароля пользователя |
| task.create | task | Создание заявки |
| task.update | task | Обновление заявки |
| task.delete | task | Удаление заявки |
| task.change_status | task | Смена статуса заявки |
| task.assign_executor | task | Назначение исполнителя |
| task.update_comment | task | Обновление комментария |
| attachment.delete | attachment | Удаление вложения из заявки |
| equipment.create | equipment | Создание актива |
| equipment.update | equipment | Обновление карточки актива |
| equipment.reassign | equipment | Переназначение ответственного |
| equipment.archive | equipment | Архивирование актива |
| software.create | software | Создание записи ПО |
| software.update | software | Обновление записи ПО |
| software.delete | software | Удаление записи ПО |
| license.create | license | Создание лицензии |
| license.update | license | Обновление лицензии |
| license.delete | license | Удаление лицензии |
| equipment_software.create | equipment_software | Установка ПО на технику |
| equipment_software.delete | equipment_software | Удаление связи актив–ПО |

Скачивание и предпросмотр вложений по проектному решению могут не фиксироваться в аудите (во избежание избыточности журнала) либо фиксироваться с отдельным action_type при необходимости.

## Доступ к журналу

Просмотр журнала аудита (поиск и фильтрация по дате, пользователю, типу операции, типу объекта) — только пользователи с ролью администратор (AuditController).
