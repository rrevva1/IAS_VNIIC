# Строгие диаграммы для просмотра

Подготовлены отдельные чистовые версии диаграмм с более строгой геометрией: фиксированные размеры блоков, выравнивание по сетке, единая толщина линий и единый стиль стрелок.

Основные файлы в формате `SVG`:

- `docs/vkr/export/strict-svg/fig_2_1_layered_architecture_strict.svg`
- `docs/vkr/export/strict-svg/fig_2_2_component_structure_strict.svg`
- `docs/vkr/export/strict-svg/fig_1_6_idef0_context_strict.svg`
- `docs/vkr/export/strict-svg/fig_1_7_idef0_decomposition_strict.svg`

Растровые копии для быстрого просмотра:

- `docs/vkr/export/strict-png/fig_2_1_layered_architecture_strict.png`
- `docs/vkr/export/strict-png/fig_2_2_component_structure_strict.png`
- `docs/vkr/export/strict-png/fig_1_6_idef0_context_strict.png`
- `docs/vkr/export/strict-png/fig_1_7_idef0_decomposition_strict.png`

Состав набора:

- `2.1` — строгая многослойная архитектура;
- `2.2` — строгая компонентная структура;
- `IDEF0 A-0` — контекстная диаграмма;
- `IDEF0 A0` — декомпозиция основных процессов.

Данные файлы подготовлены отдельно и не подменяют текущие экспортные схемы главы 1 и главы 2.
